## 一、用户决策(已确认)

1. **感知**:商店棋子 OCR base(可切模板);棋盘棋子「点击弹面板→OCR」(不做直接模板匹配,因背景变化)
2. **决策**:先 L1 规则 + L2 查表(装备合成),**不接 LLM**
3. **站位**:Phase 1 不做,只做商店操作(买/卖/刷新/升级),棋子买了自动上场

## 二、架构(基于斗地主模式修正)

### 数据流

```
scrcpy 截图(scale=2, ~50ms)
   │
   ▼
TftPerception.recognize(buttons_only=True)     ← 第1层: 轻量状态检测(模板匹配, <20ms)
   │
   ▼
TftStateRegistrar._handle 分层:
   ├─ LOBBY → 点开始游戏(固定坐标) + wait 6s
   ├─ LOADING → sleep(等加载)
   ├─ COMBAT → sleep 2s(不调 OCR, 省时间)
   ├─ 无匹配 → idle sleep 0.5s
   └─ PLANNING(轮到我操作)→ 第2层:
        ├─ recognize(全量 OCR): 金币/血量/等级/计时器/5商店slot
        ├─ 灰色检测: HSV 检测商店槽是否买不起
        ├─ decision.decide(): L1规则(买/卖/升级/刷新)
        └─ 执行 actions(tap 商店/按钮)
   │
   ▼
每轮落盘 round_NNN/ (screenshot + perception.json + actions.json)
```

### 与原方案的关键修正

| 原方案 | 问题(斗地主实战发现) | 修正 |
|--------|----------------------|------|
| OCR 识别棋子中文名为主感知 | 中文 OCR 易错(娑娜/索娜) + 无坐标 | OCR 读数字(金币/血量)为主;商店棋子 OCR + 灰色检测;棋盘棋子点击弹面板再 OCR |
| 截图 HDC ~200ms | 实测 HDC ~850ms | 直接 scrcpy **scale=2**(~50ms,斗地主验证) |
| 棋子模板匹配 | 棋盘背景变化致失效 | 棋盘不做模板;商店模板作为可选 |
| VLM 兜底 | 延迟 2-5s | 暂不接。OCR 多次投票替代 |
| 每帧全量 OCR | PaddleOCR 慢(~100ms) | **分层 handler**:先轻量模板检测状态,PLANNING 才全量 OCR |
| 无操作帧也跑感知 | 浪费 | COMBAT/idle 直接 sleep,不调感知 |

## 三、斗地主经验复用清单(TFT 子模型必读)

以下模式在斗地主实战中验证,直接搬到 TFT:

| 模式 | 斗地主实现 | TFT 应用 |
|------|-----------|---------|
| **分层 handler** | states.py `_handle`:buttons_only 先检测 → 出牌才全量 | PLANNING 才全量 OCR,其他状态 sleep |
| **scrcpy scale=2** | ScrcpyCapture(scale=2) + perception capture_scale | TFT 同样用 scale=2 减滞后 |
| **录制先于决策** | _save_debug 在 decide 前 | perception.json 先落盘,决策崩也保留 |
| **后端配置项** | run_doudizhu CAPTURE_BACKEND/INPUT_BACKEND | run_tft_scrcpy 同样配置 |
| **tap 150ms** | loop.py tap duration 固定 150ms(HOS 最小) | TFT 同 |
| **detector 阈值宽松** | detect_any_button 0.78 < recognize 0.88 | TFT detector 0.72 < recognize 0.85 |
| **_match_inline roi=None** | 传 (0,0,1,1)(None 致异常被吞) | TFT detector 同 |
| **颜色校验** | _is_red(红/黑区分) | 商店灰色检测(HSV S<30 V<150) |
| **点击后等动画** | 开始游戏 6s wait | TFT 开始游戏/回合切换同理 |

### 斗地主踩过的坑(TFT 避免)

- ❌ 别用宽 `try/except: pass` 吞异常(斗地主校准笔误被吞了 N 轮)
- ❌ 别跨帧累积 env 状态(TFT 无 env,每帧独立,天然避免)
- ❌ 别用 cv2.imread 读中文路径(用 `cv2.imdecode(np.fromfile())`)
- ❌ tap duration <150ms HOS 不识别(10ms/50ms 都试过)
- ❌ scrcpy scale=1 数据大→截图滞后→重复操作(scale=2 解决)
- ✅ 先识别后决策(识别先落盘,决策崩也保留)

#### 任务 1.2: 分层 handler + 状态补全(states.py)

**补全 RESULT 状态**:
```python
class TftState:
    LOBBY = "tft_lobby"
    QUEUE_LOADING = "tft_queue_loading"
    PLANNING = "tft_planning"
    COMBAT = "tft_combat"
    RESULT = "tft_result"           # 新增
    ALL = [LOBBY, PLANNING, COMBAT, RESULT, QUEUE_LOADING]
```

**RESULT detector**:模板匹配 `result_rank`(结算排名),阈值 0.72,roi 用 (0.3, 0.1, 0.7, 0.4)。

**RESULT handler**:点返回大厅按钮 + wait 3s。

**分层 handler 模式**(核心改造):
```python
async def _handle(self, image, context):
    round_dir = self._round_dir(context)
    # 第1层: 轻量状态检测(已由 state_machine detector 完成)
    # 第2层: 按状态决定是否需要全量 OCR
    if context.state == TftState.PLANNING:
        # 全量 OCR
        result = await self._perception.recognize(image)
        state = result.parsed
        # 先落盘再决策(斗地主教训: 决策崩也保留识别)
        self._save_debug(round_dir, image, state)
        actions = self._decision.decide(state, context)
        return actions
    elif context.state == TftState.COMBAT:
        await asyncio.sleep(2.0)
        return []
    elif context.state == TftState.LOBBY:
        actions = [Action(type="tap", x1=500, y1=900, description="开始游戏")]
        await asyncio.sleep(6.0)  # 等加载
        return actions
    elif context.state == TftState.RESULT:
        actions = [Action(type="tap", x1=500, y1=900, description="返回大厅")]
        await asyncio.sleep(3.0)
        return actions
    else:  # LOADING / idle
        await asyncio.sleep(0.5)
        return []
```

**detector 注意**: `_match_inline` 的 roi=None 时传 `(0,0,1,1)`(None 会导致异常被 except 吞,静默返回 False —— 斗地主踩过的大坑)。

#### 任务 1.3: 感知层改造(perception.py)

**加 capture_scale 参数**:
```python
class TftPerception(BasePerception):
    def __init__(self, ocr_task, tm_task=None, rois_path=None, capture_scale=1):
        self._capture_scale = capture_scale
        ...
    
    async def recognize(self, image, buttons_only=False):
        img = cv2.imdecode(...)
        h, w = img.shape[:2]
        nw, nh = w * self._capture_scale, h * self._capture_scale  # native
        
        def norm(roi_key):
            l, t, r, b = self._rois[roi_key]
            return (l/nw*w if False else l, t, r, b)  # rois.yaml 已归一化[0-1], 不需÷scale
```

**注意**:TFT 的 rois.yaml **已经是归一化 [0-1]**(不像斗地主的 PX 是像素),所以 **capture_scale 对 TFT 感知无影响**(归一化天然 scale 无关)。只需确认 scrcpy scale=2 截图后,ROI 归一化仍正确(是的,因为归一化是比例)。

**灰色检测**:
```python
def _is_gray_slot(self, img_bgr, slot_roi):
    """检测商店槽是否灰色(买不起)。HSV: S<30 且 V<150 → 灰色。"""
    slot = img_bgr[int(slot_roi[1]*h):int(slot_roi[3]*h),
                   int(slot_roi[0]*w):int(slot_roi[2]*w)]
    hsv = cv2.cvtColor(slot, cv2.COLOR_BGR2HSV)
    return (hsv[:,:,1] < 30).mean() > 0.7  # 70%+ 像素低饱和度
```

#### 任务 1.4: L1 规则修复(decision/rules.py)

**修复 _estimate_round**:用 OCR 的 stage 信息(如果有),否则用 round_timer 估算:
```python
def _estimate_round(self, perception, context):
    # 优先 OCR 读到的 stage-round 文字
    stage_text = perception.get("stage_text", "")
    if stage_text:
        return stage_text  # 如 "3-5"
    # fallback: context.round_num
    stage = 1 + context.round_num // 7
    sub = 1 + (context.round_num % 7)
    return f"{stage}-{sub}"
```

**商店灰色过滤**:

def _decide_shop(self, gold, shop_units, gray_slots):

class ItemLookup:
    def __init__(self, items_path, combos_path):
        self._items = json.load(items_path)
        self._combos = json.load(combos_path)  # {"item_a+item_b": "result"}
    
    def find_combo(self, item_a, item_b) -> str | None:
        key = "+".join(sorted([item_a, item_b]))
        return self._combos.get(key)
    
    def suggest_items(self, comp_name) -> list[str]:
        return self._items.get(comp_name, {}).get("recommended", [])

## 十、风险 + 缓解

| 风险 | 缓解 |
|------|------|
| OCR 中文棋子名误识别 | 模糊匹配(子串/字符集 ≥60%)+ 灰色检测过滤 |
| 商店灰色(买不起)误买 | HSV 颜色检测(S<30 V<150) |
| scrcpy 截图滞后 | scale=2 + wait_new=True |
| 状态检测漏检 | fallback 排除法(都不匹配 → loading/idle) |
| 点击不生效 | tap duration 150ms |
| 录制丢失 | perception 先落盘 |
| PaddleOCR 慢 | 分层 handler(非 PLANNING 不调 OCR) |
