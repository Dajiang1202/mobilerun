# TFT 状态检测模板

将以下 4 张模板图片放入此目录（PNG 格式）：

1. `lobby_play_btn.png` — 大厅"开始匹配"按钮
   - 截取方法: 在大厅界面截屏，裁剪出开始按钮区域
   - 建议尺寸: ~80x40 像素（按设备缩放）

2. `loading_spinner.png` — 排队/加载中的旋转指示器
   - 截取方法: 在排队界面截屏，裁剪出加载动画区域
   - 建议尺寸: ~60x60 像素

3. `planning_timer.png` — 备战阶段的倒计时数字
   - 截取方法: 在备战阶段截屏，裁剪出顶部倒计时区域
   - 建议尺寸: ~80x30 像素

4. `combat_indicator.png` — 战斗阶段的标识文字/图标
   - 截取方法: 在战斗阶段截屏，裁剪出左上角战斗标识
   - 建议尺寸: ~100x30 像素

## 截取技巧

1. 在游戏运行时，用 `run_tft_scrcpy.py` 启动实时预览
2. 按 `s` 键保存当前帧到 `logs/latest/`
3. 用画图工具裁剪出模板区域
4. 保存为 PNG 格式，放到此目录

## 无模板时的行为

模板缺失时，状态检测会自动降级为 fallback 模式（排除法判断），
功能可用但准确率会降低。建议至少提供 `planning_timer.png` 和 `lobby_play_btn.png`。
